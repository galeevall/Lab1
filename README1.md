### 1. Постановка задачи

> Трое жильцов решили выбросить в контейнер объемом X литров мусорные
> пакеты объемом A, B, C литров соответственно. Они подходят к контейнеру в указанном порядке и пытаются поместить пакет в контейнер. Если
> пакет не помещается в контейнер, жилец уносит свой пакет в другое место.
> Скольким жильцам не удастся выкинуть мусор в указанный контейнер? На
> вход программы подаются натуральные числа X, A, B, C.

Мы должны каждый раз проверять влезает ли пакет в контейнер или нет. Есть заданный объем контейнера и поэтому у нас есть два исхода:
1. Если пакет влезает, то есть объем пакета <= оставшегося свободного места в контейнере, то его выбрасывают в контейнер. Свободное место в контейнере уменьшается на столько,  сколько весит пакет.
2. Если пакет не влезает, то его не выбрасывают в данный контейнер, соответственно свободное место в нем не уменьшается

### 2. Входные и выходные данные

#### Данные на вход

На вход программа должна получать 4 натуральных числа. Также даны верхняя и нижняя границы получаемых
чисел.

|             | Тип                | min значение    | max значение   |
|-------------|--------------------|-----------------|----------------|
| X (Число 1) | Целое число        | 1               | 10<sup>9</sup> |
| A (Число 2) | Целое число        | 1               | 10<sup>9</sup> |
| B (Число 3) | Целое число        | 1               | 10<sup>9</sup> |
| C (Число 4) | Целое число        | 1               | 10<sup>9</sup> |

#### Данные на выход

Программа должна вывести целое число, не превышающее 10<sup>9</sup>.

|         | Тип                                | min значение | max значение   |
|---------|------------------------------------|--------------|----------------|
| Число 1 | Целое число                        | 1            | 10<sup>9</sup> |

### 3. Выбор структуры данных

Программа получает 4 натуральных числа, не превышающих по модулю 10<sup>9</sup>. Поэтому для их хранения
можно выделить 4 переменных (`x`,`a`,`b`,`c`) типа `Int`.

|                      | название переменной | Тип (в Java) | 
|-------------         |---------------------|--------------|
| X (Число 1)          | `x`                 | `int`        |
| A (Число 2)          | `a`                 | `int`        |
| B (Число 3)          | `b`                 | `int`        |
| C (Число 4)          | `c`                 | `int`        |
| peoplCount (Число 5) | `y`                 | `int`        | 

переменная peoplCount содержит результат работы программы.

### 4. Алгоритм

#### Алгоритм выполнения программы:

1. **Ввод данных:**  
   Программа считывает четыре натуральных числа, обозначенные как `x`, `a`, `b`, `c`.
2. **Инициализация данных:**
   Создаем переменную peoplCount, которая является счетчиком людей, которые не смогли выкинуть пакет в контейнер.
3. **Обработка значений:**
    - Проверяем A: если помещается уменьшаем свободное место контейнера, иначе увеличиваем счетчик на 1.
    - Проверяем B: если помещается уменьшаем свободное место контейнера, иначе увеличиваем счетчик на 1.
    - Проверяем C: если помещается уменьшаем свободное место контейнера, иначе увеличиваем счетчик на 1.
4. **Вывод результата:**
   Выводим значение peoplCount на экран.
